Ahara's Reading Room

App for Amazon Fire and Android tablets

⬇ Download the app

About 1 MB. Works without internet once installed.

Install on a Fire tablet (use the parent profile)

  1. Settings → Security & Privacy → Apps from Unknown Sources → turn on Silk Browser.
  2. Tap Download the app above. If Silk asks, choose Download or OK.
  3. When it finishes, tap the download (or open the Files app → Downloads) and tap Install.
  4. To give it to a child: Settings → Profiles & Family Library → the child's profile → Add Content → Apps → tick Ahara.

If the download will not finish

  1. Make sure you are in a parent profile, not a Kids profile. Kids profiles cannot download apps.
  2. Install the free Downloader app from the Amazon Appstore, open it and type this address:
    sujee89-dev.github.io/generative-art/downloads/ahara-reading-room.apk
